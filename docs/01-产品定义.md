# 01 产品定义说明书

## 1.1 文档目的

本文档用于界定「小洋的博客」这一个人静态站点的产品定位、目标用户、核心价值与功能边界，作为需求分析、部署实施、测试验收与运维管理的共同依据。

## 1.2 产品主题与定位

本产品是一个基于 Hexo 静态博客框架与 NexT 主题构建的个人技术博客，用于沉淀学习笔记、技术实践记录与个人简历展示。站点内容以 Markdown 文件维护，本地生成静态页面后发布到 GitHub Pages，访客通过浏览器直接访问，不依赖后端应用服务器。

## 1.3 目标用户

| 用户角色 | 说明 | 典型诉求 |
| --- | --- | --- |
| 访客（同学、同行、招聘方） | 通过公开链接浏览站点 | 快速了解作者背景，阅读文章与简历，查看标签与分类 |
| 作者本人 | 站点内容维护者 | 在本地完成写作、预览、修改与发布，操作路径简单可控 |

## 1.4 核心价值

1. 内容沉淀：将技术笔记、实践记录与个人简历以统一的博客形式长期保存。
2. 对外展示：通过公开站点向他人展示个人项目经历与技术方向。
3. 低成本托管：采用静态站点方案，部署于 GitHub Pages，无需购买与维护独立服务器。
4. 本地可控：源码与配置均保存在本地仓库，内容以 Markdown 文件管理，便于备份与迁移。
5. 统一视觉：通过自定义背景与样式文件，形成一致的页面观感与文字可读性方案。

## 1.5 功能边界

### 1.5.1 前台已包含功能

- 文章列表与文章详情页。
- 独立页面：关于（简历）页面。
- 标签页、分类页、归档页。
- 侧边栏：头像、作者信息、导航菜单。
- 全局背景图与自定义可读性样式。

### 1.5.2 后台已包含功能

- 文章与页面的新增、编辑、保存。
- 本地预览地址访问后台管理面板。
- 通过后台触发构建与部署命令。

### 1.5.3 明确不做的功能

- 用户注册、登录与多角色权限体系。
- 在线评论、留言板与消息通知。
- 数据库存储业务数据。
- 移动端原生应用。
- 在线图床与云端图片管理。
- 内容付费、电商与广告投放功能。

## 1.6 技术形态与运行环境

| 项目 | 取值 / 说明 |
| --- | --- |
| 站点框架 | Hexo 7.3.0（Node.js） |
| 站点主题 | NexT，配色方案 Mist |
| 后台插件 | hexo-admin 2.3.0 |
| 部署插件 | hexo-deployer-git 4.0.0 |
| 内容格式 | Markdown（含 front-matter） |
| 样式机制 | Stylus 自定义文件注入 |
| 托管平台 | GitHub Pages |
| 产物分支 | gh-pages |
| 本地操作系统 | Windows |
| 站点标题 | 小洋的博客 |
| 站点语言 | zh-CN |

## 1.7 术语表

| 术语 | 含义 |
| --- | --- |
| 静态站点 | 内容在本地预先生成 HTML/CSS/JS 文件，访问时由托管平台直接返回，无后端动态程序 |
| 主题（Theme） | 控制页面结构与外观的一套模板与样式文件 |
| 注入（Inject） | 主题提供的扩展点，将外部自定义样式或模板并入生成结果 |
| 产物分支 | 保存构建后静态文件、供 Pages 发布使用的 Git 分支 |
| 后台 | 本地运行的 hexo-admin 管理面板，仅用于辅助维护内容 |
